CHAPTER 01 · 2026 · 3D BROWSER GAME

Amar Agartala

A 3D farming game set in the real streets of Agartala, Tripura. Fly home to Grandpa's bari on the Haora river, ride tomtoms across town, grow paddy and Queen pineapple, tap rubber at dawn and help the neighbours with their daily kaam.

Every road, pond and lane comes from OpenStreetMap: about 8,900 houses, 700 people walking the paras, and festivals from Garia Puja to Durga Puja. No install: Three.js in the browser, with one set of game rules shared by the browser and a Cloudflare Worker on D1.

  • Three.js
  • TypeScript
  • OpenStreetMap
  • Cloudflare Workers
  • D1

CHAPTER 02 · 2026 · DEV TOOL

Safari DevTools

Debugging on an iPhone usually means a cable, a Mac and a lot of patience. Safari DevTools puts the whole toolkit inside the page: console, elements, CSS, network mocking, audits and a design overlay.

It talks to Playwright and MCP too, so AI agents can use it. One file, zero dependencies.

CHAPTER 03 · 2026 · CHROME EXTENSION

Reflex

Agentify the web you already use. Reflex reads a site's existing forms, semantic HTML and accessibility metadata, finds the WebMCP tools hiding inside, and lets a human approve which ones an AI agent can use.

No rewrite needed. If the site is accessible, it's already agent-ready.

  • TypeScript
  • Manifest V3
  • WebMCP
  • ARIA
  • AI agents
